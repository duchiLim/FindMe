# FindMe: 유기동물 임시보호 및 입양 매칭 플랫폼 기획안

## 1. 프로젝트 개요
**FindMe**는 전국 유기동물 보호소의 데이터를 실시간으로 연동하여, 유기동물들에게 새로운 가족을 찾아주고 안전한 임시보호처를 매칭해주는 플랫폼입니다.

## 2. 핵심 목표
- 유기동물 공고의 접근성 향상
- 임시보호 및 입양 절차의 간소화 및 디지털화
- 유기동물 입양 문화 활성화

## 3. 주요 기능
### 3.1 실시간 유기동물 공고 조회
- 전국 보호소의 유기동물 정보를 실시간으로 리스트업
- 지역, 품종, 성별, 특징별 맞춤형 필터링 제공
- 고해상도 동물 사진 및 현재 상태(보호 중, 입양 가능 등) 정보 제공

### 3.2 입양 및 임시보호 매칭
- 관심 있는 동물에 대한 '찜하기' 기능
- 앱 내 상담 신청 및 예약 시스템
- 입양/임시보호 신청서 작성 및 관리 기능

### 3.3 사용자 편의 기능
- 위치 기반 주변 보호소 안내
- 유기동물 발견 및 실종 신고 게시판 운영
- 입양 성공 후기 및 커뮤니티

## 4. 데이터 활용 계획
- **활용 데이터**: 농림축산식품부 공공데이터 포털 '유기동물 조회 서비스' API
- **활용 내용**: 
    - 전국 보호소별 유기동물 상세 정보 (사진, 특징, 발견 장소 등)
    - 보호소 위치 및 연락처 데이터
    - 실시간 공고 상태 업데이트 반영

## 5. 기술 스택 (예정)
- **Architecture**: Clean Architecture (Domain, Data, Presentation)
- **Language**: Kotlin
- **UI**: Jetpack Compose, Navigation Compose
- **Network**: Retrofit2 (공공데이터 API 연동)
- **DI**: Hilt
- **Local DB**: Room (최근 본 동물, 관심 동물 저장)

## 6. 하단 탭 구조 (Navigation)

FindMe는 **4탭 Bottom Navigation**을 기본으로 합니다. 입양·임시보호 앱의 핵심 여정(탐색 → 보호소 연락 → 관심 저장 → 내 활동 관리)을 최소 탭 수로 커버하는 구조입니다.

### 6.1 추천 탭 구성

| 순서 | 탭 | Route | 핵심 역할 | 연관 기획 |
| :---: | :--- | :--- | :--- | :--- |
| 1 | **홈** | `home` | 유기동물 목록, 필터, 검색 | §3.1 실시간 공고 조회 |
| 2 | **보호소** | `shelter` | 보호소 목록, 연락처, (추후) 지도 | §3.1·§3.3 보호소 안내 |
| 3 | **찜** | `favorite` | 관심 동물 저장, 입양 후보 관리 | §3.2 찜하기 |
| 4 | **마이** | `my` | 최근 본 동물, 신청 내역, 설정 | §3.2·§3.3 사용자 편의 |

```
┌─────────┬─────────┬─────────┬─────────┐
│   홈    │  보호소  │   찜    │   마이   │
│  탐색   │  연락   │  관심   │  관리   │
└─────────┴─────────┴─────────┴─────────┘
```

**이 구조를 추천하는 이유**
- **홈**을 첫 탭으로 두어 앱 실행 직후 공고 탐색이 가능합니다. (유기동물 앱의 Primary Job)
- **보호소**를 2번 탭에 두어 MVP 단계에서도 지역별 보호소 조회·연락 가치를 바로 제공합니다. (찜 기능 구현 전 빈 탭 노출 방지)
- **보호소**는 공공데이터 API(시도/시군구/보호소)와 자연스럽게 연결되며, 입양 전화·방문 문의 진입점이 됩니다.
- **찜**을 별도 탭으로 분리해 재방문·비교 탐색을 쉽게 합니다. (Phase 2 이후 핵심 액션)
- **마이**에 신청서·설정·최근 본 동물을 모아 탐색 탭의 복잡도를 낮춥니다.

**의도적으로 넣지 않은 탭**
- **커뮤니티·실종신고**: §3.3 후순위 기능. MVP 이후 상단/마이 내부 메뉴로 확장합니다.
- **입양·임보 전용 탭**: 찜 + 마이(신청 내역)로 분산하는 편이 탭 수를 줄이고 IA가 단순합니다.

### 6.2 탭별 상세 (로드맵)

#### 홈 (`home`) — MVP
- 유기동물 카드 리스트 (사진, 품종, 상태, 보호소명)
- 필터: 지역(시도/시군구), 축종, 상태, 기간
- 카드 탭 → 동물 상세 화면 이동

#### 보호소 (`shelter`) — Phase 2
- 시도/시군구 선택 → 보호소 목록
- 보호소명, 주소, 전화번호
- (추후) 지도 연동, 길찾기

#### 찜 (`favorite`) — Phase 2
- Room에 저장한 관심 동물 목록
- 찜 추가/삭제, 정렬(최근 추가순)
- (추후) 입양·임시보호 신청 바로가기

#### 마이 (`my`) — Phase 2
- 최근 본 동물
- 입양/임시보호 신청 내역 (추후)
- 알림, 앱 설정, API/버전 정보

### 6.3 상세 화면 (Bottom Bar 미표시)

탭 바깥으로 push되는 화면에서는 하단 탭을 숨깁니다.

| 화면 | Route | 진입 경로 |
| :--- | :--- | :--- |
| 동물 상세 | `animal/{desertionNo}` | 홈·찜 리스트에서 카드 선택 |

탭 전환 시 **상태 유지** (`saveState` / `restoreState`)로 각 탭의 스크롤·필터를 보존합니다.

## 7. 기대 효과
- 유기동물의 재입양률 증가 및 안락사 비율 감소
- 투명한 보호소 정보 제공을 통한 신뢰도 확보
- 입양 희망자와 유기동물 간의 효율적인 매칭 환경 제공
