## 1. 문서 개요

### 1.1 목적
FindMe(유기동물 입양·보호소 연결 앱)에 **광고를 도입해 지속 가능한 운영 비용(API·스토어·유지보수)을 충당**하되, 입양 탐색 UX와 **동물 복지·신뢰**를 해치지 않는 범위에서 수익을 확보한다.

### 1.2 범위
| 포함 | 미포함 (본 문서) |
| :--- | :--- |
| 광고 플랫폼·형식·노출 위치 정책 | SDK 연동·코드 구현 |
| UX·윤리 가이드 | 실제 광고 단가·매출 보장 |
| 단계별 로드맵 (MVP → Phase 3) | 스토어 등록·AdMob 계정 개설 절차 상세 |
| 개인정보·동의·정책 요구사항 | A/B 테스트 인프라 |

### 1.3 기본 원칙

| 원칙 | 설명 |
| :--- | :--- |
| **탐색 우선** | 동물 목록·상세·전화 문의 흐름을 광고가 가로막지 않는다 |
| **감정 존중** | 유기·입양 맥락에서 자극적·혐오·과장 광고를 배제한다 |
| **투명성** | 광고 영역은 콘텐츠와 시각적으로 구분(`광고` 라벨)한다 |
| **점진 도입** | 트래픽·리뷰 리스크를 줄이기 위해 노출 지면·형식을 단계적으로 확대한다 |
| **선택권** | (Phase 3) 유료 **광고 제거** 또는 후원 옵션 검토 |

## 2. 수익화 목표 및 가정

### 2.1 목표
- **1차:** 월 운영비(도메인·스토어 개발자 등록 분摊, API 트래픽 여유) 수준의 **보조 수익**
- **2차:** DAU 1,000+ 구간에서 **네이티브·배너 혼합**으로 안정적 eCPM 확보
- **비목표:** 입양 절차 자체를 유료화하거나, 보호소 연락(전화) 전 **강제 전면 광고**

### 2.2 KPI (도입 후 측정)
| 지표 | 설명 |
| :--- | :--- |
| **ARPU** | 활성 사용자당 일/월 광고 수익 |
| **eCPM / Fill Rate** | 지면별 노출·채움률 |
| **광고 CTR** | 과도한 CTR은 오클릭·정책 위반 신호 |
| **이탈률 Δ** | 광고 도입 전후 세션 길이·상세 진입 수 |
| **스토어 평점·리뷰** | 「광고 많음」 키워드 모니터링 |
| **전화 CTA 전환** | 상세 → `ACTION_DIAL` (광고가 입양 문의를 감소시키지 않는지) |

## 3. 광고 플랫폼

### 3.1 1차 권장: Google AdMob
| 항목 | 내용 |
| :--- | :--- |
| **이유** | Android 표준, 배너·네이티브·전면·보상형 지원, UMP(동의) SDK |
| **적합 형식** | Adaptive Banner, Native Advanced, (후순위) Interstitial |
| **주의** | 가족·동물 앱 → **콘텐츠 등급·광고 카테고리 차단** 설정 필수 |

### 3.2 2차 검토 (Phase 3+)
| 플랫폼 | 용도 |
| :--- | :--- |
| **Meta Audience Network** | Mediation으로 fill rate 보완 |
| **쿠팡 파트ners / 네이버 애드** | 반려동물 용품 **제휴**(광고 SDK와 별 트랙) |
| **직접 제휴** | 사료·병원·보험 등 **스폰서 네이티브** (편집 콘텐츠 형태) |

> MVP는 **AdMob 단일**로 시작하고, mediation은 트래픽 증가 후 도입한다.

## 4. 광고 형식 정의

| 형식 | 코드(AdMob) | UX 영향 | FindMe 적합도 |
| :--- | :--- | :--- | :--- |
| **Adaptive Banner** | `Banner` | 하단 고정, 탭/CTA와 겹칠 수 있음 | △ (일부 화면만) |
| **네이티브** | `Native` | 목록에 카드 형태 삽입 | ◎ (홈·보호소 목록) |
| **전면** | `Interstitial` | 화면 전환 시 풀스크린 | △ (빈도 엄격 제한) |
| **보상형** | `Rewarded` | 시청 후 혜택 | ○ (광고 제거·부가 기능) |
| **앱 오프닝** | `App Open` | cold start | ✕ (스플래시와 충돌, 1차 제외) |

## 5. 노출 지면 정책

### 5.1 노출 **금지** 구간 (Hard No)

| 화면 / 순간 | Route | 이유 |
| :--- | :--- | :--- |
| **스플래시·최초 로딩** | 앱 시작 | 첫인상·브랜드 훼손 |
| **동물 상세** | `animal/{desertionNo}` | 입양 판단·전화 CTA 집중 구간 |
| **보호소 상세** | `shelter/{careRegNo}` | 연락·유기동물 목록 진입 |
| **마음에 두기 Empty** | `favorite` | 공감·CTA(유기동물 보러 가기) 방해 |
| **전화 다이얼 직전/직후** | `ACTION_DIAL` | 전환 순간 끊김 |
| **오류·Empty(재시도)** | 공통 | 불안정 UX |
| **설정·개인정보·동의** | `my/*` | 법적·신뢰 구간 |

### 5.2 노출 **허용** 구간 (우선순위)

#### Phase 1 — MVP 광고 (리스크 최소)

| 지면 | Route | 형식 | 위치 |
| :--- | :--- | :--- | :--- |
| **마이 탭 하단** | `my` | Adaptive Banner | Footer(`FindMe v…`) **위**, Bottom Nav **위** 여백 확보 |

- 홈·상세·마음에 두기에는 **광고 없음**
- 리뷰·정책 리스크 최소, 동의·측정 파이프라인 검증용

#### Phase 2 — 목록 네이티브

| 지면 | Route | 형식 | 규칙 |
| :--- | :--- | :--- | :--- |
| **홈 목록** | `home` | Native | **본문 목록**에만 삽입. **오늘 등록·입양 임박 큐레이션 내부 금지** |
| **보호소 목록** | `shelter` | Native | 카드 **N개마다 1개** (예: 8~10간격) |
| **오늘 등록 전체** | `home/today` | Native | 동일 간격 규칙 |
| **보호소 유기동물 목록** | `shelter/.../animals` | Native | 그리드/리스트 아이템 사이 |
| **최근 본 전체** | `my/recent` | Native | (선택) 간격 동일 |

**홈 네이티브 삽입 규칙 (와이어프레임)**

```
┌─────────────────────────────┐
│  [검색·필터]                 │
├─────────────────────────────┤
│  오늘 등록  (큐레이션 — 광고 X) │
│  ┌──┐ ┌──┐ ┌──┐ [더보기]    │
├─────────────────────────────┤
│  입양 임박  (큐레이션 — 광고 X)│
├─────────────────────────────┤
│  [동물 카드]                 │
│  [동물 카드]                 │
│  ... (8~10개마다)            │
│  ┌─ 광고 ─ Native ─────────┐ │
│  │  Sponsored · 광고       │ │
│  └─────────────────────────┘ │
│  [동물 카드]                 │
└─────────────────────────────┘
```

#### Phase 3 — 전면·보상형 (선택)

| 지면 | 형식 | 조건 |
| :--- | :--- | :--- |
| **탭 전환** | Interstitial | **금지 권장** — 대안: 상세 이탈 후 **세션당 최대 1회**, **3분 쿨다운** |
| **설정** | Rewarded | 「30분 광고 숨기기」등 **명시적 opt-in** |
| **마이** | 배너 유지 + **광고 제거 IAP** | 일회성/월 구독 검토 |

### 5.3 Bottom Navigation과의 관계

| 항목 | 정책 |
| :--- | :--- |
| Bottom Bar **위** | Adaptive Banner 가능 (Phase 1 마이만) |
| Bottom Bar **아래** | 시스템 내비게이션 바 — 광고 배치 **금지** (`navigationBarsPadding` 유지) |
| **top-level 탭** | 홈·보호소·마음에 두기: Phase 1 **배너 없음** (탭 전환 UX 보호) |

## 8. 기술 아키텍처 (개략)

> 구현은 본 문서 범위 외. Clean Architecture 배치 **안**만 기록.

```
┌─────────────────────────────────────────┐
│  presentation/                          │
│  · AdBannerComposable / AdNativeItem    │
│  · HomeScreen, ShelterScreen, MyScreen  │
├─────────────────────────────────────────┤
│  domain/                                │
│  · AdPlacementPolicy (enum)             │
│  · ShouldShowAdsUseCase (IAP·동의)      │
├─────────────────────────────────────────┤
│  data/                                  │
│  · AdMobDataSource (SDK 래퍼)           │
│  · UserPreferences: ads_consent, no_ads   │
└─────────────────────────────────────────┘
```

| 모듈 | 역할 |
| :--- | :--- |
| `app` | AdMob App ID, ProGuard, `AndroidManifest` meta-data |
| `presentation` | Compose UI, **광고는 Presentation만** (Domain은 정책만) |
| `domain` | 「이 지면에 광고 가능한가」 비즈니스 규칙 |
| `data` | SDK 초기화·로드·노출 이벤트 (Analytics 연동 선택) |

**Gradle (참고)**  
`com.google.android.gms:play-services-ads` · UMP SDK — 버전은 구현 시 [libs.versions.toml](../../gradle/libs.versions.toml)에 고정.

## 9. 단계별 로드맵

### Phase 1 — 파일럿 (2~4주)
- [ ] AdMob 계정·앱 등록·테스트 광고 ID
- [ ] UMP 동의 Flow (EEA 최소)
- [ ] **마이 탭 하단 배너** 1지면만
- [ ] Firebase/Analytics 이벤트: `ad_impression`, `ad_click` (선택)
- [ ] 내부 QA: Bottom Nav·Footer와 겹침 없음

### Phase 2 — 목록 네이티브 (4~8주)
- [ ] 홈·보호소·하위 목록 **Native** (간격 8~10)
- [ ] 큐레이션 섹션 **광고 제외** 로직
- [ ] 개인정보 처리방침·Play 데이터 안전 업데이트
- [ ] eCPM·이탈률 2주 모니터링 후 간격 조정

### Phase 3 — 수익 최적화 (트래픽 확보 후)
- [ ] Mediation (Meta 등)
- [ ] **광고 제거 IAP** 또는 후원 (Ko-fi 등 링크)
- [ ] (선택) 보상형 「30분 무광고」
- [ ] (비권장) 전면 — 쿨다운·상한 엄격 적용 시에만 A/B

## 14. 요약

FindMe 광고는 **「입양 탐색을 방해하지 않는 보조 수익」** 으로 설계한다.  
**Phase 1:** 마이 탭 배너만 → **Phase 2:** 홈·보호소 목록 네이티브(큐레이션·상세·전화 구간 제외) → **Phase 3:** IAP·mediation.  
동물·입양 맥락에 맞는 **카테고리 차단·광고 라벨·동의** 를 전제로, eCPM보다 **전화 CTA·체류 시간** 을 우선 KPI로 본다.
